# LaCoope – Web Application

LaCoope es una aplicación web desarrollada para la gestión de tareas internas dentro de una organización.

El sistema permite organizar tareas, visualizar información de clientes y facilitar la gestión diaria del área técnica.

Este proyecto fue desarrollado como parte de mi portfolio personal para demostrar habilidades en desarrollo full stack.
